# Cats & Dogs 🐱🐶

Кооперативный 2D-платформер на HTML Canvas в стиле Fireboy and Watergirl: кот и собака проходят уровни вместе, собирают алмазы, находят ключ и доходят до своих дверей.

## Особенности

- **3 уровня** с фиксированными паттернами платформ (Level 1: ступеньки, Level 2: зигзаг, Level 3: горка)
- **Случайные двери** — позиции дверей меняются при каждой загрузке уровня
- **Ключ** — появляется на средней платформе, открывает обе двери
- **Враги** — только на Level 3, 4 паттерна (patrol / rush / random / chase), скорость 0.3–0.6
- **Статичная камера** — весь уровень виден целиком (поле зрения 1920×1080)
- **Не требует внешних ассетов** — все объекты рисуются геометрическими примитивами и текстом

## Управление

| Герой | Движение | Прыжок |
|---|---|---|
| Cat | A / D | W |
| Dog | ← / → | ↑ |

Дополнительно:

- **Enter** — старт / повтор
- **R** — перезапуск уровня
- **Esc** — пауза

## Запуск

```bash
python -m http.server 8080
```

Открой `http://localhost:8080`.

## Технологии

- HTML + CSS
- Vanilla JavaScript
- Canvas API (вся графика рисуется через fillRect, path, arc, текст)
