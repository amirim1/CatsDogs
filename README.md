# CatsDogs

2D кооперативный платформер, вдохновлённый механиками игры «Огонь и вода».
Проект разработан с использованием HTML5 Canvas, JavaScript, OpenCode (Harness), Git и GitHub.
## Быстрый старт

https://amirim1.github.io/CatsDogs/

## Описание игры

Игрок управляет двумя персонажами:

* котом;
* собакой.

Основная задача — пройти уровень, найти ключ и довести обоих персонажей до соответствующих дверей.

В игре реализованы:

* 5 игровых уровней;
* система платформ и коллизий;
* враги и получение урона;
* система неуязвимости;
* двери и ключи;
* переходы между уровнями;
* анимации персонажей;
* звуковые эффекты;
* GitHub Pages deployment.

---

## Управление

### Кот

* `A / D` — движение
* `W` — прыжок

### Собака

* `← / →` — движение
* `↑` — прыжок

---

## Игровые механики

* Для прохождения уровня необходимо:

  1 Найти ключ.
  2 Довести кота до своей двери.
  3 Довести собаку до своей двери.

* Алмазы являются дополнительными collectible-объектами.

* После получения урона персонаж получает временную неуязвимость.

---

## Анимации

Для каждого персонажа реализованы:

* Idle
* Run
* Jump
* Fall
* Hurt

Всего:

* 44 кадра анимации на персонажа;
* 88 кадров анимации в проекте.
